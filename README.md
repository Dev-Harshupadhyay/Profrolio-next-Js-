# Harsh Upadhyay — Portfolio 🚀

Personal portfolio of **Harsh Upadhyay** — BCA student & self-taught full-stack web developer from India.

**Live:** [profrolio-next-js.vercel.app](https://profrolio-next-js.vercel.app)

## ✨ Features

- Modern dark premium design with typewriter hero, glow accents & smooth animations
- Fully responsive — mobile-first
- **SEO optimized** — meta tags, OpenGraph, Twitter cards, JSON-LD (Person schema), auto-generated `sitemap.xml` & `robots.txt`
- Google Search Console verification built-in
- Lightweight: ~97 kB first load JS (static, prerendered)

## 🛠️ Tech Stack

- [Next.js 14](https://nextjs.org/) (App Router) + TypeScript
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide Icons](https://lucide.dev/)

## 🏃 Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## 📦 Build

```bash
npm run build
npm start
```

## 📁 Structure

```
app/          # Layout (SEO metadata), page, sitemap, robots
components/   # Navbar, Hero, About, Skills, Projects, GitHub, Contact, Footer
data/site.ts  # All content in one place — edit here to update the site
public/       # Profile photo & project screenshots
```
